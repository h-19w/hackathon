# WAKE UP

First-person **3D campus horror** set in **Wenzhou-Kean University · Building C · 03:33 AM**.

Your phone is the light. Luke is gone. Shadows respect the beam — not your knife.

## How it works (30 seconds)

1. **Light first, then hit** — hold the beam ~0.5s to stagger; then swing.
2. **Battery is life** — drain while moving; stand under working lights to heal + recharge.
3. **Four tasks open F2** — office diary, kitchen knife+water, lab mouse, library keycard.
4. **Do not call his name** on Floor 2.

**Route:** G Classroom → F1 Corridor → F2 Neural Lab boss → time-loop ending.
